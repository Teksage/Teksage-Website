# Mobile Translation QA

Use the production-connected Android/iOS release build. For each language,
switch once and complete every checkbox before moving to the next language.
Onboarding may require an approved test device or clearing test-app data.

For every non-English language, compare text density with English and verify
that headings, buttons, cards, navigation labels and dialogs do not clip or
overflow after the reduced locale text scale is applied.
