# Manual Translation QA

Use this checklist to test translated production screens after deployment.

- Website checklist: `docs/MANUAL_TRANSLATION_QA_WEBSITE.md`
- Mobile checklist: `docs/MANUAL_TRANSLATION_QA_MOBILE.md`
- Translation procedure: `docs/TRANSLATION_WORKFLOW.md`

## Test order

Complete the website first:

1. Open `https://my.teksage.app`.
2. Sign in with an appropriate production test account.
3. Select Tamil.
4. Test every website page in the Tamil section.
5. Record failures before changing language.
6. Repeat the complete page sequence for Hindi, Telugu, Kannada, Malayalam and
  Marathi.

Then complete the mobile app:

1. Install/open the release build connected to production.
2. Select Tamil.
3. Test every mobile screen in the Tamil section.
4. Record failures before changing language.
5. Repeat the complete screen sequence for Hindi, Telugu, Kannada, Malayalam
  and Marathi.
